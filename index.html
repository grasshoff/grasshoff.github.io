Famulus.
AI that shows its sources.

Famulus is a way of working with AI in the humanities and sciences in which every answer can be traced back to a source. Models and data stay on the institution's own machines, every page and passage of a collection has a permanent address, and every result carries a record of how it came about.

Gerd Graßhoff, Humboldt-Universität zu Berlin, Forschungsinstitut des Deutschen Museums

Famulus in brief

A famulus is, in the old university sense, the assistant who serves a scholar. The agents of this platform are meant to be exactly that: assistants who show their working.

The problem

AI models answer fluently and cite unreliably. They invent sources, forget where a statement came from, and, to work on unpublished or sensitive material, usually need it to be sent to servers outside the institution.

The idea

Treat a collection as a reference that has to prove itself. Each document, page and passage gets a stable address; each citation is composed only from recorded bibliographic data; each statement carries a grade of evidence. A model working on such a collection can quote a reference that exists, or say that it is missing.

What you get

Answers that can be checked line by line, work that can be reproduced from its trace, and an infrastructure that runs on your own hardware. Researchers work in notebooks, where text, code and sources stand side by side.

Three ideas that carry the platform

Everything else on this page is an elaboration of these three.

First idea

Famulus Reference

A global reference for AI models

Each collection is served as a reference data source. A model asks it for grounding and receives not only the text but the address, the citation, the provenance and the grade of evidence of every item it may use.

fr:schemehartmanncollectionbsb00028171document0137pageprint1segment

The address of one printed figure in the Hartmann collection

What it achieves

  • An address for everything. The address is persistent and is used verbatim in every claim the system makes.
  • Citations never invented. A citation is composed only from recorded bibliography. Where data is missing, the gap is stated.
  • Graded evidence. Each statement is documented, inferred, a hypothesis, or a gap, together with the checks behind the grade.
  • A trace for every answer. Which tool, model and input produced which output is recorded; a later request can read the same items in the same state.

How it works

All collections live in one local lake of data and are served by one MCP server, so any AI assistant, notebook or search tool reaches them the same way. The same data can be harvested by library catalogues (OAI-PMH, JSON-LD/DCAT, IIIF). Any institution can run the same server over its own lake, so the reference is distributed rather than centralised; the registry that would connect such nodes exists as a stub, and the server's deployment on the central machine is prepared.

Second idea

From literate programming to literate AI

Knuth's root, and what Famulus makes of it

“Instead of imagining that our main task is to instruct a computer what to do, let us concentrate rather on explaining to human beings what we want a computer to do.”

Donald E. Knuth, Literate Programming, 1984

Knuth proposed that a program be written as a document for human readers, with the code woven into the explanation. Famulus takes this over for AI. The explanation becomes the specification an agent works from, and the sources it cites become addressable.

Famulus Lektor

Lektor

Ein Satz ist sachlich validiert, wenn jede seiner tragenden Aussagen aus Belegen folgt, keine widerlegt ist und der Satz nichts sagt, was einem früheren Satz des Aufsatzes oder einem Register widerspricht. Jeder andere Satz ist nicht validiert. Ein drittes Urteil gibt es nur für Sätze ohne Sachgehalt, etwa Fragen oder Aufforderungen.

Famulus Visualization

Visualization

Famulus Visualization macht aus einem Datennarrativ eine Abbildung: in einem Typst-Papier, auf einer HTML-Seite, als 3D-Szene oder als Animation. Jede Abbildung liest ihre Daten aus der Datei, in der sie stehen, und hebt genau die Elemente hervor, von denen die Aussage handelt.

CRITICAL ANNOTATIONTypeset draft

The Famulus Probe Lab

Normalise, filter, classify: generating critical annotation for the items of a reference storage

How a probe, one sentence of the scholar, produces critical annotation for the items of a reference storage in three stages: normalise (every expression gets a footnote with grounds and a grade, no value without a ground), filter (the justified keys of the probe become one query) and classify (entailment, contradiction, independence, and weak or abductive support). One worked case on the Kármán Nachlass; the limits are stated.
